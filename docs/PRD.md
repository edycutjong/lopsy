# Lopsy — Product Requirements Document

> **Emotional Hook**: An LP provider watched her position bleed $2,400 over 3 weeks because she didn't know the Zap-Out button existed.

## Problem Statement
LP positions silently bleed value through impermanent loss. No forensics tool with emergency exit.

## Solution Overview
Closed position forensics + emergency Zap-Out. Analyze IL/P&L, one-click exit for underwater positions.

## Core Features (MVP)
1. Historical LP position analysis
2. Realized IL/P&L calculation
3. Pool comparison table
4. Zap-Out emergency exit (MANDATORY — 40% of rubric)
5. Position health indicators

## Success Metrics
- All SDK features demonstrably integrated
- Demo flow works end-to-end

## Out of Scope
- ❌ Portfolio rebalancing
- ❌ Yield farming
- ❌ Custom strategies
